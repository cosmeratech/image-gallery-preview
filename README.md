## Image Gallery & Preview Viewer
An interactive image gallery showcasing a clean grid layout with consistent image sizing and a full-screen preview viewer. Clicking on any image opens an overlay preview with smooth transitions, allowing users to view images clearly without leaving the page.

## Features

Grid-Based Gallery – Displays images in a balanced 2×2 layout with uniform sizing
Image Preview Viewer – Click an image to open a full-screen overlay preview
Overlay Controls – Close the preview using a button or background click
Smooth Transitions – Subtle animations for opening and closing the preview
Responsive Layout – Adapts seamlessly to mobile and smaller screen sizes
